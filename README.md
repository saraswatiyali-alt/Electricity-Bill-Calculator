Electricity Bill Calculator ⚡
A simple Electricity Bill Calculator developed using the C programming language. This project calculates electricity charges based on the units consumed by customers.

Features
Add customer details
Calculate electricity bills
Display customer records
Search customers by ID
Menu-driven interface
Technologies Used
C Programming
Structures
Functions
Arrays
Loops and Conditional Statements
How to Run

bash
gcc electricity_bill.c -o electricity_bill
./electricity_bill
Purpose
This project is developed for learning C programming concepts and understanding real-world billing systems.# Electricity-Bill-Calculator
